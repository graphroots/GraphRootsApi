# Security

This repository’s GraphQL host is a local reference implementation with **no authentication**. Do not expose it on a public network.

If you find a vulnerability in this tree, please report it privately via GitHub’s [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on the repository (Security advisory / Report a vulnerability), rather than opening a public issue.
